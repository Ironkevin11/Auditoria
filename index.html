Ecosistema de seguridad

Adentro del edificio también hay reglas.

Endpoint son los guardias, Network las cámaras, Identity and Access la recepción. Data and Apps son las cajas fuertes: cuatro dominios que vigilan, controlan, escanean y mantienen segura la información una vez ya se entró.

Panorama · 4 pilares · 1 ciclo
01

Data Monitoring

Vigilancia continua y automatizada de quién toca un dato, cuándo y desde dónde. El sistema aprende qué es normal para cada usuario y alerta cuando algo se sale de esa línea base.

Recolección de logs

Cada acceso queda registrado: usuario, hora, IP, qué hizo.

Línea base

El sistema aprende el patrón normal de cada usuario.

Detección de anomalías

Un acceso fuera de patrón dispara una alerta automática.

Respuesta

La alerta bloquea la sesión o notifica a un analista.

02

Data Access Control

Decide quién puede hacer qué con cada dato, antes de que lo intente. El monitoreo vigila después; el control de acceso previene desde el inicio.

RBAC

Los permisos se asignan a roles, no a personas: admin, editor, analista.

Cifrado

En reposo y en tránsito, para que nadie intercepte lo que viaja por la red.

Revisión periódica

Cada cierto tiempo se revoca el acceso que ya no se necesita.

03

Application Scanning

Analiza el código y el comportamiento de una aplicación para hallar vulnerabilidades antes de que sean explotadas.

SAST

Revisa el código fuente sin ejecutarlo, buscando patrones peligrosos.

DAST

Ejecuta y "ataca" la app de forma controlada para ver cómo responde.

OWASP ZAP

Herramienta que se integra al pipeline y puede bloquear un despliegue inseguro.

04

App Security Management

Administración continua de la seguridad en producción: parches, configuración y dependencias que hay que mantener al día siempre.

Parches y dependencias

Saber qué librerías usa la app y actualizarlas rápido.

Configuración segura

Cabeceras HTTP que evitan que un atacante intercepte la conexión.

Cumplimiento

Seguir estándares como OWASP Top 10 de forma permanente.

Un ciclo, no piezas sueltas

Scanning encuentra una falla → Security Management decide cómo corregirla. Access Control define quién toca qué dato → Monitoring vigila que nadie se salte esa regla.

Scanning→ Security Management→ Access Control→ Monitoring
